# SPLIT

![Flutter](https://img.shields.io/badge/Flutter-%2302569B.svg?style=for-the-badge&logo=Flutter&logoColor=white)
![Dart](https://img.shields.io/badge/dart-%230175C2.svg?style=for-the-badge&logo=dart&logoColor=white)
![Supabase](https://img.shields.io/badge/Supabase-3ECF8E?style=for-the-badge&logo=supabase&logoColor=white)

Une application mobile développée avec **Flutter** utilisant **Supabase** comme backend pour la gestion des données en temps réel et l'authentification. L'application permet de jouer à deux en temps réels à des mini-jeux via un système de room.

---

## Stack Technique

* **Frontend :** Flutter (Dart)
* **Backend / Base de données :** Supabase (PostgreSQL)

---

## Prérequis

Avant de commencer, assurez-vous d'avoir installé :

* [Flutter SDK](https://flutter.dev/docs/get-started/install)
* [Git](https://git-scm.com/)
* Un compte [Supabase](https://supabase.com/)

---

## Installation

1. **Cloner le projet**

    ```bash
    git clone https://github.com/Padomala/flutter-project-r507
    cd flutter-project-r507
    ```

1. **Installer les dépendances**

    ```bash
    flutter pub get
    ```

1. **Lancer l'application**

    ```bash
    flutter run
    ```
